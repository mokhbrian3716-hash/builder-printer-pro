# 🏗️ Builder Printer Pro

**Builder Printer Pro v7.0** is a desktop drawing application built with **Python and PyQt6**, designed for creating and editing building plans and technical drawings.

## ✨ Features

* ✏️ Pencil drawing
* 📏 Lines and dimensions
* ⬜ Rectangles and filled rectangles
* ⭕ Ellipses and filled ellipses
* 🔺 Polygons
* ⭐ Star shapes
* ➡️ Arrows
* 🧹 Eraser
* 💨 Spray tool
* 🖋️ Calligraphy tool
* 🏠 Wall drawing tool
* 🪣 Smart fill tool
* 📝 Text tool
* 🎨 Custom colors
* 🌈 Gradient support
* 🌓 Shadow effects
* 📐 Measurement tools
* 🔍 Zoom in/out
* 🎯 Snap to grid
* 📏 Grid and ruler
* 🗂️ Layer management
* ↩️ Undo / Redo
* 📋 Copy, Cut and Paste
* 💾 Project saving and loading
* 💾 Auto-save
* 🖼️ PNG and JPG export
* 🖥️ Full-screen mode
* 📊 Project statistics
* ⌨️ Keyboard shortcuts
* 🌙 Dark user interface

## 🛠️ Technologies

* **Python**
* **PyQt6**
* **Qt6**
* **Pickle** for project file serialization

## 📋 Requirements

* Python 3.10 or newer
* PyQt6

Install the required dependency:

```bash
pip install PyQt6
```

## ▶️ Run the Application

Clone the repository:

```bash
git clone https://github.com/mokhbrian3716-hash/builder-printer-pro.git
```

Open the project directory:

```bash
cd builder-printer-pro
```

Run the application:

```bash
python builder_printer.py
```

## 💾 Project Files

Builder Printer Pro uses the `.buil` file format to save projects.

Project files can contain information such as:

* Layers
* Shapes
* Colors
* Line widths
* Opacity
* Rotation
* Gradients
* Shadows
* Text
* Fonts

## 🎯 Purpose

This project was created as a desktop drawing and building-plan design application using Python and PyQt6.

It can serve as a foundation for developing more advanced CAD-like drawing and architectural design software.
